# aurora-navigator

travelers guide for spectral exploration: a one-page reference for the **qu-bit aurora** spectral reverb. warp, time, blur, reflect, mix and atmosphere, freeze and reverse, fft sizes, shift functions, options.txt, firmware, calibration and the manual's patches, with diagrams.

source: the qu-bit aurora manual (v1.7.4).

part of the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with qu-bit electronix.
